# SHRTX — Brand Identity System v1

## Brand Positioning

SHRTX is positioned as a modern browser-native utility infrastructure brand.

Core brand attributes:

- Precision
- Speed
- Lightweight execution
- Privacy-first architecture
- Developer-grade reliability
- Minimal overhead
- Technical clarity

The visual identity intentionally avoids:

- Generic AI startup aesthetics
- Gaming/esports styling
- Overly playful SaaS branding
- Heavy gradient dependence
- Excessive visual noise

The goal is to communicate:

> "Engineered carefully. Built for real workflows."

---

# Primary Identity

## Primary Wordmark

### Structure

SHRTX uses a custom engineered wordmark system.

Design philosophy:

- Geometric construction

- Confident
- Controlled

# Signature Element — The X

The X is the defining identity element.

It represents:

- Routing
- System intersections
- Deep linking
- Modular pathways
- Browser infrastructure
- Cross-platform utility workflows

## Visual Construction

The X is built from:

- Directional vector geometry
- Split path architecture
- Negative space tension
- Asymmetric interruption

This creates:

- Motion perception
- Technical uniqueness
- High silhouette recognition

# App Icon System

## Philosophy

The app icon is derived from the X structure.

This ensures:

- Brand cohesion
- Recognition consistency
- System scalability
- Better favicon recognition

---

## App Icon Principles

The icon must work at:

- 16x16
- 32x32
- 64x64
- Mobile launcher size
- Browser favicon size

Priority:

- silhouette clarity
- recognizability
- contrast
- simplicity
